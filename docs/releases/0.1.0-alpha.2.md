# Legacy2UEFI 0.1.0-alpha.2 — notes de version

Date : 2026-11-20 · Statut : **alpha, image testée sur matériel** (ThinkPad 4414WBF : Omarchy installé et démarré, E4), remplace 0.1.0-alpha.1.

## Correction

- **« BOOT MISMATCH! » au démarrage** (vu sur le ThinkPad 4414WBF avec l'image alpha.1) : OpenDuet vérifie une
  signature de 14 octets dans le secteur de démarrage de la partition (octets 496 à 509) et refuse une signature
  nulle ; il affichait alors ce message, attendait 3 s, puis trouvait quand même l'écran Legacy2UEFI par une
  seconde recherche. L'outil d'image écrit désormais 14 octets non nuls, différents à chaque construction, comme
  l'installateur officiel d'OpenCore.

## Test de l'image alpha.1 (2026-11-20, ThinkPad 4414WBF)

Clé écrite avec balenaEtcher : démarrage sur l'écran Legacy2UEFI (après le message ci-dessus), écran adapté au
1024×768, clé Ventoy et disque interne SATA 500 Go (sans système) listés. Preuve :
`tests/evidence/lenovo-thinkpad-4414wbf/2026-11-20/image-alpha1-screen.png`.
